# Проверка контракта данных и файлового коннектора, 0.9.0

Дата: 9 ноября 2026 года. [Описание формата](COMMENT_FILE_EXCHANGE.md).

## Реализовано

- Проверка полного снимка сотрудников, документов и отдельных комментариев.
- Проверка результатов с исходными идентификаторами и хешем снимка.
- UTF-8 JSON, явные временные границы, точные числа, неопределённость и бесконечность.
- Файловый источник и приёмник, повторяемая публикация без перезаписи.
- Синтетическая выгрузка и исполняемый пример полного обмена с активностью 2,1,0.
- Установка не требует новых сторонних зависимостей; прежние API не менялись.

## Проверки

Добавлены 39 проверок контракта/коннектора и две проверки примера.
Полный локальный набор: **780 passed**, 63.21 с (Windows, Python 3.12.1).
Проверены дубли, повреждённый JSON, числовые ID, неразрешённые ссылки, неполнота,
периоды и смещения UTC, неизвестные схемы/поля, ограничения размера, статусы чисел,
подмена снимка, независимость копий, повторная и конкурентная публикация,
конфликт содержимого, невозможность превратить run_id в путь и сбой записи.

Операции жёстких ссылок проверяются в обычном окружении ОС: ограниченная среда
выполнения Windows их запрещает. После запуска вне этого ограничения проверки
прошли без изменения алгоритма публикации. Неподдерживаемая файловая система
или недостаток прав должны приводить к явной ошибке, а не неатомарной записи.

Editable-установка и сборка sdist/wheel 0.9.0 прошли. Полная и минимальная установки
вне checkout проверены tools/check_distribution.py: полный wheel — **780 passed**,
95.91 с; минимальный без NetworkX/pandas/SciPy — **242 passed**, 17.32 с.
Полный набор сохраняет прежние API и PythonExamples. Проверен импорт из site-packages
и версия 0.9.0; pip check полной установки пройден. Окружения созданы по constraints/py312.txt.
Дополнительно проверено чтение снимка без site-packages (`python -S`), то есть только
на стандартной библиотеке. Готовый JSON результата сверён с контрактом и снимком.

Матрица GitHub Actions: Windows/Linux × Python 3.12/3.13 × полная/минимальная
установка. Итоговая ссылка добавляется после отправки проверенного кода.

Это проверка программного контракта и синтетических данных. Подключение к реальной
конфигурации 1С, сверка полноты выгрузки с базой и импорт в её регистры не выполнялись.
