# Проверка второго этапа, версия 0.3.0

Дата: 8 ноября 2026 года. Среда: Windows, Python 3.12.1.

Реализованы C01/C04/C05, неизменяемые контексты, координаты, конечные матричные
данные, численная политика и диагностика. Общая рациональная арифметика
встроена в прежние классы без введения общей билинейной алгебры.
Публичный контракт и ограничения: [CORE_DATA_API.md](CORE_DATA_API.md).

Проверки:

- Editable-установка 0.3.0 в отдельное окружение проекта.
- Полный набор: **538 passed**, 47.85 с; NumPy 1.26.3, NetworkX 3.6.1,
  SymPy 1.14.0, pytest 9.0.3.
- Сборка sdist и wheel через `python -m build --no-isolation`.
- Установка wheel в отдельное окружение вне checkout, обновлённое с 0.2.1.
  Путь импорта `polyform_algebra.core` явно проверен: `venv/Lib/site-packages`.
  Там находятся только копии tests/examples, исходного пакета рядом нет.
- Полный набор установленного пакета: **538 passed**, 47.52 с;
  NumPy 2.5.4, NetworkX 3.7, SymPy 1.14.0, pytest 9.2.0, pandas 3.1.1.
- `get_version()` и `__version__` возвращают `0.3.0`.
- `examples.exact_contexts` показывает точное суммирование `1/3+1/6=1/2`,
  сохранение изолята, перестановку координат и ненулевую границу с
  коэффициентом `1/10¹²`.
- `git diff --check` не выявил ошибок форматирования.

Добавлены 43 тестовых случая и две автоматические проверки нового примера
(запуск и отсутствие вычислений при импорте). Покрыты T12/T29/T33/T38:
идентичность и порядок пространств, неизменяемость, точные коэффициенты,
ошибки входных типов/меток, несовместимость режимов, переполнение и исчезновение
ненулевого числа при численном переводе. Прежние 493 проверки сохраняются.

При интеграции обнаружена и устранена несовместимость с NumPy: старые
метрические вызовы на обычных целых/float данных сохраняют численный результат.
Для точного результата в старой алгебре используются явные рациональные
коэффициенты. Отдельная регрессия закрепляет это поведение.

Решатели этапов 3–4 и строгий формальный интерфейс этапа 5 не реализовывались.
Совместимость всех объявленных Python/ОС не проверялась; Python ≥3.8 в metadata
сохранён. Публикация в PyPI не выполнялась.
