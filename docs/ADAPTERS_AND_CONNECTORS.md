# Адаптеры и коннекторы, версия 0.8.0

Дата: 9 ноября 2026 года. Разделение математических операций, представления данных
и внешнего обмена. Формулы, результаты и области допустимости не менялись.

## Расположение и совместимость

| Импорт | Назначение | Состояние |
| --- | --- | --- |
| `adapters.pandas` | DataFrame ↔ LabeledMatrix/Laplacian, VertexValues → Series | Реализация перенесена из matrix |
| `adapters.matrix_networkx` | NetworkX ↔ прежние численные матрицы | Реализация перенесена из matrix |
| `adapters.networkx` | NetworkX ↔ строгий Network | Сохранён контракт 0.7.0 |
| `adapters.records` | Запись вычисления и сетевой диспетчер | Без изменений |
| `connectors` | Контракты внешнего чтения и публикации | Новый пакет без внешних зависимостей |
| `matrix.pandas`, `matrix.networkx` | Прежние пути импорта | Повторно экспортируют те же функции новых модулей |

Примеры и PythonExamples могут продолжать использовать прежние импорты.
Не добавлены предупреждения об устаревании, меняющие вывод программ. Сигнатуры,
типы результата, исключения, порядок меток и создание независимых копий сохранены.
Новый код может импортировать матричные адаптеры непосредственно из adapters.
Определяющий модуль функций теперь adapters; математические классы не перемещены.

Примеры новых импортов:

```python
from polyform_algebra.adapters.pandas import from_dataframe, to_dataframe, to_series
from polyform_algebra.adapters.matrix_networkx import from_networkx as matrix_from_graph
from polyform_algebra.adapters.networkx import from_networkx as network_from_graph
from polyform_algebra.connectors import DataSource, ResultSink
```

У двух NetworkX-адаптеров намеренно разные имена модулей. Матричный принимает
направленные простые графы, работает численно, допускает неявный порядок узлов,
но отклоняет мультиграфы. Строгий принимает неориентированные графы, требует полный
явный порядок вершин, поддерживает exact/numeric и суммирование параллельных рёбер.
Объединение функций под одним именем изменило бы контракт версии 0.7.0.

## Коннекторы

`DataSource` и `ResultSink` — независимые абстрактные классы стандартной библиотеки:

- `read_snapshot(query: Mapping[str, Any]) -> Mapping[str, Any]`;
- `publish(result: Mapping[str, Any], *, idempotency_key: str) -> Mapping[str, Any]`.

Наследник должен реализовать соответствующий метод. Нельзя создать базовый класс
и получить фиктивно успешный пустой результат. Источник только для чтения не обязан
иметь метод записи. Приёмник возвращает подтверждение транспорта.

Схемы запроса, снимка и результата согласуются с прикладным сценарием; математическое
ядро их не интерпретирует. Реальный коннектор отвечает за подключение, права,
полноту данных, ошибки передачи и повторные запросы. Идемпотентность — обязательство
конкретного приёмника, а не готовая реализация базового класса: одинаковый ключ
не должен создавать повторные эффекты, конфликтующий результат должен отклоняться.

В этом изменении нет соединений, HTTP-клиента, чтения базы 1С или записи в неё.
Следующие шаги: согласовать пилотную выгрузку, реализовать сценарий анализа и
конкретный коннектор по [прикладному плану](PMG_APPLIED_INTEGRATION_PLAN.md).

## Границы зависимостей

Коннекторы не импортируют ядро, матрицы, pandas, NumPy или сетевые SDK.
Адаптеры зависят от представляемых математических объектов; pandas/NetworkX
подключаются при вызове соответствующих операций, а не при импорте адаптера.
Ядро и матричные алгоритмы не импортируют коннекторы и адаптеры. Исключение — два
старых модуля совместимости matrix: в них остались только импорты и список экспортов.

Конкретные веса, нормировки, группировка событий и трактовка голосов принадлежат
будущим прикладным сценариям. Преобразование двудольного графа, Дирихле,
балансировка и центральности остаются математическими операциями.

## Проверка

`test_adapter_relocation.py` проверяет совместимые импорты, направленность,
изолированные вершины, порядок осей, независимость копий и сохранение различий
двух NetworkX-контрактов. `test_connector_contracts.py` проверяет абстрактность,
разделение чтения/записи и границы импортов; включён также в минимальную поставку.
Существующие тесты продолжают обращаться к старым путям и проверяют их поведение.
