## Матрица GitHub Actions

Настроены Python 3.12/3.13 × Windows/Linux × полная/минимальная установка — 8 заданий.
Они собирают wheel через sdist, тестируют установленный пакет вне checkout и
сохраняют JSON с версиями зависимостей и XML pytest. Запуск матрицы требует отправки
workflow в GitHub; итог и ссылка будут добавлены после выполнения.

Проверки используют constraints/py312.txt и constraints/py313.txt.
Совместимость API/PythonExamples подтверждается полным набором, граница ядра —
отдельным минимальным окружением и тестом, запрещающим необязательные и тематические
импорты. Ссылки на определения PMG сохраняются отдельно от версии кода.

Публикация в PyPI не выполняется. ИИ-сервер, UI и тематические расширения не созданы:
поставляется вычислительное ядро и транспортный адаптер для их дальнейшей разработки.
