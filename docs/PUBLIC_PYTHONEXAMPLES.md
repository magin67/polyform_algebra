# Совместимость с публичным разделом PythonExamples

Публичный раздел: <https://magin67.github.io/pmg-notes/ru/pythonexamples/>.
Исходники: [pmg-notes/v5, PythonExamples](https://github.com/magin67/pmg-notes/tree/v5/pmg-library/ru/PythonExamples).

Для проверок версий 0.4.0–0.6.0 зафиксирован коммит заметок
`c909ddf8a590c69ed0a82fe48ca496e88fb707e0`. Прочитаны обе языковые версии:
по шесть практических заметок и оглавление. Вычислительные блоки RU/EN
совпадают; тест отдельно контролирует это совпадение зафиксированных копий.

| Публичная заметка | Модуль проекта / контрольные результаты |
| --- | --- |
| Установка библиотеки и запуск примеров | Проверка K3: τ=3, R=2/3; запуск всех шести модулей ниже |
| Взвешенная цепочка | `examples.introductory.note01_weighted_chain`: τ=2; R=1, 1/2, 3/2; при токе 2 A потенциалы (3,1,0), мощность 6 |
| Геометрия единичного треугольника | `examples.introductory.note05_triangle_geometry`: det Gram=1/3, площадь²=1/12 |
| Вариации связей треугольника | `examples.introductory.note06_single_edge`, `note07_two_edges`: τ=5 и 8; R12=2/5, R23=1/2 соответственно |
| Экспоненты пути P5 и цикла C4 | `examples.introductory.note10_path_cycle`: τ=1 и 4; R15=4 и R12=3/4 соответственно |
| Удаление ребра и моста | `examples.introductory.note10_edge_deletion`: после удаления ребра C4 τ=1, R12=3; после удаления моста τ=0 и нормировка на всём графе запрещена |

`tests/fixtures/pythonexamples_v5.json` хранит дословные вычислительные
Python-блоки, URL исходной страницы и Git blob SHA. Тест
`tests/test_public_pythonexamples.py` запускает последовательные блоки каждой
страницы в общем пространстве переменных и проверяет числа, а не только
отсутствие исключений. Он не обращается к сети и не меняет установку пакета.

Команды установки, магические команды Colab и обёртки subprocess не включены
в исполняемый снимок. Все шесть упомянутых модулей уже запускаются общим
`tests/test_examples.py`; импорт примеров также проверяется на отсутствие
вычислений и вывода. Эти проверки выполняются и для установленного wheel.

Публичная инструкция установки закреплена за старым коммитом библиотеки
`d4c82cf51b2a049ca00f09d1ae752c9d23648f7a`. Её команды не переключались на
новую рабочую ветку автоматически; страницы и публикация сайта не менялись.
Проверена совместимость опубликованного вычислительного кода с текущим
пакетом, а не развёртывание Colab или сайта.

При дальнейших изменениях API сохранять эти тесты. При изменении заметок
обновлять снимок после прочтения новых блоков и проверять ожидаемые числа
независимо. Ревизия снимка должна меняться явно; зелёный тест старой копии
не доказывает совместимость с будущей редакцией сайта.
