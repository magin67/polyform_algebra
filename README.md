# Алгебра полиформ / Polyform Algebra

Python-библиотека для вычислений с точками, векторами, симплексами, их границами
и квадратичными полиформами по заметкам [PMG](https://github.com/magin67/pmg-notes/tree/v5/pmg-library).

## Контексты и точная арифметика

`polyform_algebra.directed.DirectedNetwork` вычисляет исходящий лапласиан,
остовные потенциалы и точную балансировку. Для связных балансовых графов
доступны центрированный гриниан, односторонние резистенсы и грамиан вершин.
Перебор направленных лесов предназначен для малых графов.
Пример `python -m examples.balanced_graphs`.

`polyform_algebra.combinatorics` вычисляет целочисленные потенциалы
`second_kind_potential(block_sizes)`, `first_kind_potential(cycle_lengths)`
и `path_cycle_potential(cycle_lengths, path_lengths)`. Размеры блоков
и длины компонент задаются положительными целыми числами. Для смешанного
типа длины считаются в дугах, изолированные вершины опускаются, а петля
имеет длину один. Пример `python -m examples.combinatorial_potentials`.

`polyform_algebra.toponomes` группирует заданные разбиения и остовные леса
по положительным типам, вычисляет произведение типов через частичные
сопоставления, считает цветовые классы и строит коэффициентные таблицы.
Перебор лесов и цветовых классов рассчитан на небольшие графы.
Пример `python -m examples.partition_toponomes`.

`vertex_toponome` применяет корневой вес к каждому типу перед группировкой.
`laplacian_polynomial` возвращает точные коэффициенты `det(I + tL)`
от свободного члена к старшему, а `rooted_forest_weight` вычисляет вес лесов
с одним заданным корнем на компоненту через главный минор исходного лапласиана.
Пример `python -m examples.polynomial_toponomes`.

`polyform_algebra.core.circumsphere(net)` вычисляет резистивный радиус
и би-координаты центра описанной сферы связного графа в рациональных
дробях. Пример: `python -m examples.exact_circumspheres`.

`degree_potential(net)` и `laplacian_circumsphere(net)` из
`polyform_algebra.core` вычисляют точный потенциал степеней, би-координаты
центра и квадрат линейного радиуса в геометрии с грамианом `L`.
Пример: `python -m examples.degree_geometry`.

`polyform_algebra.core.IsotropicExtension` строит изотропное расширение
резистивной метрики связного графа в точной рациональной арифметике.
В его контексте доступны локальные вершины, выделенный нуль-вектор `z`,
аффинный вес, скалярное произведение, знаковая квадратичная норма и центр
элемента веса один. Пример: `python -m examples.isotropic_centers`.

## Первые вычисления

Версия установленной библиотеки: `polyform_algebra.get_version()` или
`polyform_algebra.__version__` (текущая версия — 0.9.0). Оба значения берутся
из metadata пакета; единственный источник номера — `pyproject.toml`.
После изменения версии повторите установку, в том числе editable.
В неустановленной копии исходников запрос версии вызывает
`importlib.metadata.PackageNotFoundError`; импорт математических классов доступен.

В 0.2.1 исправлено ложное бесконечное сопротивление при больших проводимостях.
Компактная запись границ теперь требует аффинного веса 1; для иных весов
используйте `Simplex([a, b, ...]).boundary()`. Это ограничение компактного
представления, а не общего граничного оператора.

```python
from polyform_algebra import Point, Simplex, Polyform, quForm

a, b, c = Point.create_list("abc")
assert a + a == 2 * a
assert Simplex([(a, b)]) * Simplex([(b, c)]) == Simplex([(a, b, c)])

laplacian = quForm([(a, b)]) + quForm([(b, c)])
metric = laplacian.exp()
assert metric.norm(quForm([(a, c)])) == 2
assert Polyform.zero().exp() == Polyform.one()
```

## Область реализации

- Публичная алгебра ограничена поддерживаемыми квадратичными формами.
- Отрицательные коэффициенты в алгебре допустимы. Конструкторы сетей требуют
  конечные неотрицательные проводимости, отсутствие направлений и петель.
- `from_laplacian(matrix, points)` принимает различные объекты `Point` в порядке строк.
  `from_networkx(graph, return_points="dict")` возвращает соответствие меток точкам.
- `@` возвращает половину полярной формы для поддерживаемых объектов первого грейда;
  численная оценка выполняется через `metric.norm(...)`. Другие грейды явно отклоняются.
- `to_diagonal_quform(basis)` оставляет квадраты координат без смешанных членов.
  Это не полный формальный квадрат; применение требует согласованной диагональной метрики.
  Старое имя `to_quadratic_form` сохранено.
- Нормировка метрики несвязного графа запрещена при нулевом остовном коэффициенте;
  сама алгебра, экспонента и ненормированный потенциал остаются доступны.

Подробности и история исправлений: [обзор реализации](docs/IMPLEMENTATION_REVIEW.md).
Первоначальный [аудит вводной серии](docs/PMG_INTRO_AUDIT.md) содержит исторические
предложения; актуальное ограничение квадратичными формами имеет приоритет.

## Проверка и сборка

```powershell
python -m pytest -q
python -m build
```

Тесты включают регрессии и проверки запуска всех примеров. Сборка создаёт wheel
и исходный архив в `dist/`. Wheel содержит только `polyform_algebra`; примеры и
заметки доступны в репозитории и исходном архиве.

## Работа с двух компьютеров

Перед началом: `git status`, затем при чистом рабочем дереве `git pull --ff-only`.
После изменений: запустить тесты, создать коммит и выполнить `git push`.
Если есть незакоммиченные изменения или расходящаяся история, сначала сохранить
и разобрать их; не применять принудительное перезаписывание.
Виртуальное окружение создаётся отдельно на каждом компьютере и не хранится в Git.
